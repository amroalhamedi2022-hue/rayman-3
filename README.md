# Rayman 3 Android port workspace

Independent Android-first compatibility work for [Rayman 3 Readvanced](https://github.com/RayCarrot/Rayman3Readvanced). Upstream pin: `dd8fb6d9ea34decedc4e57d4c5deebc008b8adbd` (GPL-3.0 upstream). This repository contains integration code and tests only. No ROMs, original game resources, private artwork, save data, or private project archives are included. Upstream is fetched directly at build time; no game data is needed for compilation checks. Not an official Ubisoft product.

Goal: retain the GBA game's gameplay, animation timing, collision and level data while adapting platform services for Android ARM64. HD rendering is a separate future layer. No playable APK is claimed until device verification.
