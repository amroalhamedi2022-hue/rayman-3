# ARM64 SoLoud candidate
Pinned official SoLoud source e82fd32c1f62183922f08c14c814a02b58db1873. Use the original MiniAudio backend rather than reimplementing playback or silently muting the engine. CMake builds actual SoLoud C API, without no-sound substitution. Target arm64-v8a/API 23 and 16 KiB ELF alignment.
Readvanced has 423 managed native imports. Static comparison with the chosen official SoLoud header identified three absent declarations: Soloud_setPanAbsoluteEx, TedSid_loadToMem, TedSid_loadFileToMem. These are NOT shimmed with approximate behavior. The CI separately measures real ELF exports, and reports full_abi=false if gaps persist. This is not proof of runtime audio fidelity. N-Gage OpenMPT dynamic loading is outside the initial GBA Android target and is not silently marked supported. A device test must validate initialization, actual audible playback, music/sound event timing, pause/resume and output route changes before integration.
No original game assets, ROM, or private project files are included. CI publishes ABI diagnostics only.
